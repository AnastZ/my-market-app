Проектная работа Sprint 7, развитие проекта из Sprint 6.
Добавление сервиса платежей с использованием OpenAPI, использование Redis для кэширования товаров.

Сервис витрины интернет-магазина принимает запросы от фронтэнда на порт, 
указанный при запуске контейнера (MARKET_PORT). Сервис витрины взаимодействует с сервисом платежей, 
используя указанный URL сервиса платежей (PAYMENT_URL)., 
Сервис платежей использует порт, указанный при запуске контейнера (PAYMENT_PORT).
Сервис витрины интернет-магазина использует БД H2 для хранения сущностей и Redis для кэширования.
Схема БД генерируется при запуске программы.

Запуск Redis, сервиса платежей, сервиса витрины интернет-магазина и БД H2:
1. В консоли открыть папку с исходными файлами, в этой папке находятся следующие обязательные файлы: src, target, pom.xml, docker-compose.yml, Dockerfile.
2. Из папки с исходными файлами вызвать команду:
docker-compose up --build

Для завершения работы вызвать команду:
docker-compose down

Запуск тестов:
1. В консоли открыть папку с исходными файлами (где лежит pom.xml).
2. Выполнить команду:
mvn test
